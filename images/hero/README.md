# Hero Images

Drop your hero slideshow photos here.

Expected filenames (referenced in index.html):
  hero-1.jpg
  hero-2.jpg
  hero-3.jpg
  hero-4.jpg
  hero-5.jpg

You can add more slides by:
1. Adding the image file here (hero-6.jpg, etc.)
2. Adding a matching <img class="hero-slide"> block in index.html

Recommended specs:
- Landscape orientation
- At least 1920 × 1080px (larger is fine)
- JPEG, high quality (80–90%)
