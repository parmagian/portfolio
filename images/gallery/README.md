# Gallery Images

Drop your Recent Work thumbnails here.

Expected filenames (referenced in index.html):
  gallery-1.jpg
  gallery-2.jpg
  gallery-3.jpg
  gallery-4.jpg
  gallery-5.jpg
  gallery-6.jpg

You can add or remove photos by editing the .work-grid section in index.html.
Each image is displayed at a 3:2 aspect ratio, cropped to fill — so any size works.

Recommended specs:
- Landscape orientation (3:2 ratio natural)
- At least 900 × 600px
- JPEG, high quality (80–90%)
